紀錄 git 常用指令

前言

git 是目前大家常用的VCS(版控系統), 網路上有許多免費的服務, 可以讓開發者上傳原始碼, 享受免架git server就可以得到版控的服務.

常用的git vcs 服務有:

  • github
  • gitlab
  • gitgee (中國)
